题目：数控恒压/恒流双模式直流电源设计

分值构成：基本功能实现60分 + 发挥性能指标30分 + 设计报告10分

一、设计任务

设计并制作一台数控直流电源，可工作在恒压输出（CV）与恒流输出（CC）两种模式，

支持参数调节与实时测量显示。电路方案、处理器型号、电源拓扑结构均不做限制，要求原理

清晰、可实施性高、性能稳定，重点考察恒压/恒流闭环控制原理与工程实现能力。

二、基本功能要求（60分）

1. 供电方式

可采用实验室直流稳压电源供电（如12V/24V），或自带简易整流滤波电路。

2. 输出模式

具备恒压（CV）、恒流（CC）两种工作模式，可通过按键或开关手动切换。

3. 恒压模式指标


• 输出电压范围：0～12V 连续可调

• 调节步进不大于 0.1V

• 带载情况下电压输出稳定，无明显漂移

4. 恒流模式指标

• 输出电流范围：0～1A 连续可调

• 调节步进不大于 0.1A

• 带载情况下电流输出稳定，无明显波动

5. 显示与操作

• 实时显示输出电压、输出电流

• 支持按键加减调节参数

• 清晰指示当前工作模式（CV/CC）

6. 基础保护

具备输出过流/短路保护功能，保护动作可靠，不损坏器件。

三、发挥性能指标（30分）

1. 精度提升（8分）

电压、电流设定与实测误差 ≤ ±1%，显示分辨率不低于 0.01V/0.001A。

2. CV/CC 自动切换（8分）

负载变化时，可在恒压、恒流模式间自动平滑切换，切换过程无冲击、无掉压。

3. 纹波与动态性能（7分）

恒压满载输出时纹波较小；负载突变时，输出超调量小、恢复时间短。

4. 效率与稳定性（7分）

电源整体转换效率较高，长时间连续工作输出不发热异常、参数不漂移。

四、设计报告要求（10分）

1. 结构完整（3分）

包含任务分析、方案论证、系统框图、硬件电路、软件流程、测试方法等完整内容。

2. 原理清晰（3分）

准确阐述恒压、恒流控制原理，关键参数计算过程完整合理。

3. 测试详实（2分）

记录完整实测数据，对比指标要求，分析误差及改进方向。

4. 格式规范（2分）

图文规范、图表清晰、排版整洁，符合工程设计报告要求。

五、说明

1. 处理器不限：可采用51单片机、STM32、Arduino、MSP430、FPGA等任意控制器。

2. 拓扑不限：可采用线性稳压（LM317、串联调整管）或开关拓扑（Buck等），鼓励使用实验室现有器件完成设计。

3. 评分侧重：控制原理正确性、系统实现简洁性、运行稳定性与工程规范性。
